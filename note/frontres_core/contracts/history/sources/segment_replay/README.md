`note/frontres_segment_replay/` on 2026-07-13.

These files include plans, checklists, logs, intake snapshots, engineering
compendia, and external-code references. They are evidence and history, not
active contracts. Do not scan this directory during ordinary task routing, and
do not let a source file override the active contract registry.

Read a source file only when an active contract cites unresolved evidence, the
user requests historical reconstruction, or a contradiction cannot be resolved
from active contracts and current code/runtime evidence.

folder. Other paths preserve the original relative subdirectories.

# FEMR Testing Views

These files are current derived views:

- `test_control_board.md`: current coverage and active gates.
- `test_inventory.md`: reusable tests and current gaps.
- `semantic_objects.md`: cross-module objects and lifecycle invariants.
- `impact_rules.md`: how a change expands its test scope.

`evidence_ledger_*.md` files are dated evidence and may preserve historical
observations. They do not override current contracts or views.

Refresh the four current views when Architecture, active contracts, modules, or
test ownership changes. Do not append chronological debugging history to them.

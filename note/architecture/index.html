MOSAIC-FEMR Architecture Snapshot

These maps are meant to be read side by side with code. They share Code Block IDs and concept colors, so a design idea can be traced from concept to file to interface boundary.

Durable launcher: ./note/architecture/open_atlas.command. It owns the local server lifecycle and opens the detailed human review directly.
